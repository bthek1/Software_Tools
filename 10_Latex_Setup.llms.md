## Installation

``` bash
sudo apt update
sudo apt install texlive-full
```

``` bash
sudo apt install texlive-latex-extra biber
```

\*\* Thats all you need\*\*

### Additional Tools

Texmaker: A popular LaTeX editor.

``` bash
sudo apt install texmaker
```

Pandoc: A universal document converter.

``` bash
sudo apt install pandoc
```
